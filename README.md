# 清华校园技能包

> 🔍 **还不知道这是干什么的？** 装好后直接问 AI"这个是做什么的"，AI 会给你介绍，不用读文档。

一站式搞定清华校园事务的 AI 技能包。

查课表、看成绩、交作业、约图书馆座位、看校内通知、查文献、收发邮件——这些以前要挨个打开网站才能办的事，现在对 AI 说一句话就能完成。

## 它是什么

把清华校园的十几项日常服务整合进同一个 AI Agent。你只需完成**一次初始化**（约 5 分钟），之后用自然语言对话即可：

```
"查看待办"             → 网络学堂作业/待办/批改反馈
"我的课表"             → 本周课表
"我的成绩"             → 成绩单与绩点
"培养方案"             → 学分还差多少
"我的第二成绩单"       → 课外经历记录
"图书馆还有座位吗"     → 各馆座位余量
"帮我约个北馆二楼的座位" → 座位预约
"最近有什么通知"       → 校内通知
"帮我搜本书"           → 图书馆馆藏检索
"帮我查文献"           → 文献检索
"看邮件"               → 收发邮件
```

## 快速开始

第一次使用，对 AI 说 **"开始初始化"**，AI 会自动：

1. **装环境** — 自动下载所需依赖与浏览器内核（无需你操作）
2. **配凭据** — 你只需提供清华统一认证的**学号**和**密码**（几乎所有功能都要用）
3. **登录** — 自动完成统一认证登录，可能需回复一个短信验证码

> 前提：电脑已安装 Python 3.10 或更高版本。

## 需要你提供什么

| 字段 | 必填 | 影响功能 |
|------|:---:|----------|
| 学号 + 统一认证密码 | ✅ | 网络学堂/课表/成绩/培养方案/选课/第二成绩单/图书馆/通知 全部要用 |
| 姓名/学号（可选） | ⬜ | 作业文件命名 |
| Scopus API Key（可选） | ⬜ | 文献检索 |
| DeepSeek API Key（可选） | ⬜ | AI 预批改、文献摘要 |
| 邮箱授权码（可选） | ⬜ | 收发邮件 |

> 只配学号+密码即可使用大部分功能；其余字段按需补配。

## 隐私承诺

- 凭据用操作系统安全存储加密，**只存在本机，不出设备**
- AI 不会在对话里复述你的密码
- 展示信息时学号/姓名自动脱敏

## 项目结构

```
skill/
├── SKILL.md     # AI 操作手册（初始化流程、凭据字段、路由、故障处理）
├── README.md    # 本文件（项目介绍）
├── campus/      # 技能包主体：主 SKILL 路由 + 各子技能（网络学堂/课表/成绩/图书馆/邮件…）
├── docs/        # 开发文档与接口逆向笔记
└── tests/       # 冒烟测试
```

## 面向开发者

- 各子技能开发标准：`campus/SKILL.md` 及 `docs/subskill-template.md`
- 接口逆向笔记：`docs/course-reverse-notes.md`、`docs/library-reverse-notes.md`
- 所有脚本 stdout 输出 JSON，进度写 `campus/runtime/logs/campus.log`
